# 小岛日记 (Little Island Diary)

单机、横屏、纯触屏的像素风动物岛屿生活模拟游戏。Godot 4.2.2（GL Compatibility），目标平台 Android。
地图为 **64×64 格（4096 格，16px/格）**，包含森林、断崖高地、河流与桥、果园、草原、沙滩与码头。

## 目录结构

```
project.godot          引擎配置（640×360 基准、canvas_items+expand、Nearest 像素滤波、海洋蓝清屏色）
main.tscn              主场景入口，仅挂载 main.gd
main.gd                全部游戏逻辑（地形/岛建/动物/UI/存档）
sprites/tools_items/   31 张工具与物品图标
sprites/ui/            18 张系统 UI 图标
.github/workflows/     推送 main 分支自动构建 APK
```

## 本地运行

1. 安装 **Godot 4.2.2**（标准版，非 .NET）。
2. 打开 Godot → 导入 → 选择本目录的 `project.godot`。
3. 按 F5 运行。桌面端可用鼠标模拟触屏（`pointing/emulate_touch_from_mouse=true`）。
4. 首次运行会自动导入 `sprites/` 下的 PNG（生成 `.import` 与 `.godot/`，这两个都不进版本库）。

## 打包安卓 APK

- **自动**：推到 `main` 分支，GitHub Actions 会下载 Godot 4.2.2 + 导出模板，生成 `animal_island.apk`，在 Actions 页面的 Artifacts 里下载。
- **手动**：工程已带 `import_etc2_astc=true` 与横屏设置，在 Godot 里「项目 → 导出 → Android」即可（需自行配置 Android SDK 与签名）。

## 操作说明（横屏触屏）

| 区域 | 作用 |
|---|---|
| 左下虚拟摇杆 | 按住移动（八方向，斜向不加速），松手立即停下 |
| 点击地面 | 自动寻路走过去，遇到树木/房屋/河流/悬崖会自动绕路 |
| 右下 互动 / 使用 / 取消 | 与小动物、贝壳、喷泉、信箱、商店交互；使用当前快捷栏物品 |
| 顶部左侧 | 现实日期、季节、时段、金币 |
| 顶部右侧 | 岛建、背包、地图、菜单 |
| 底部 6 槽快捷栏 | 点选物品；背包里可把物品放入指定槽位 |

摇杆优先于自动寻路：一旦碰摇杆，正在进行的寻路立即取消；打开背包/商店/地图等弹窗时也会暂停并清除寻路。点击水面或不可达位置会自动改选最近的可站立点，找不到则给出提示。

**岛建模式**：9 个工具（地形 / 铲平 / 高地 / 水域 / 道路 / 植物 / 建筑 / 装饰 / 移动），右侧可调画笔 1×1~3×3、连续涂抹 / 矩形框选、单指移视角、切换子样式、撤销（最多 25 步）/ 重做。

- 画笔以手指所指格为中心，向四周扩展。
- 「高地」工具点「切换子样式」可改为**坡道**：在悬崖脚下放一块坡道，才能走上二层高地（没有坡道时高地不可攀爬，小动物也不会上去）。
- 水面不能直接铺路 / 种植 / 建造，要先用「铲平」填土造陆。
- 道路铺在高地上不会把高地压平。

## 居民（本地 AI）

5 位居民（兔子莉莉 / 猫咪奈奈 / 狐狸阿洛 / 小熊布朗 / 企鹅波波）各自拥有：

- **人格参数**：社交、好奇、活力、沉稳、讲究（0~1，各不相同）
- **兴趣**：阅读、海、花、料理、运动、音乐、探索，会影响行动选择
- **需求**：社交、心情、精力、饥饿，随时间衰减，由对应行动补充
- **记忆**：容量 12 条，超出后遗忘最旧的；重要事件会记住并在对话里提起
- **关系**：与玩家的好感 0~100；居民之间有独立的两两关系（可能交好也可能闹别扭）
- **行动**：回家休息 / 找点吃的 / 找人聊天 / 去海边玩 / 长椅看书 / 逛杂货铺 / 四处散步

决策是本地效用函数：需求缺口 × 人格权重 + 时段偏好 + 兴趣加成 − 距离惩罚 + 小随机，每 2~4 秒或行动结束时重算一次，不会每帧计算。居民走真实 A* 路径、遵守碰撞与地图边界，不上高地、不穿墙、不瞬移。

想看某个居民“为什么这么做”：设置 → **查看居民 AI 状态**，会列出当前行动、选择原因、四项需求、两两关系与最近一条记忆；控制台也会打印 `[AI] 名字 -> 原因` 决策日志。

| 设施 | 位置 | 用途 |
|---|---|---|
| 图书馆 | 广场西北 | 读书 +知识；可翻鱼类图鉴 |
| 食堂 | 广场东北 | 花铃钱用餐，移速 +20% |
| 运动场 | 西南 | 跑步（移速+20%）；查看居民关系 |
| 家具店 | 东侧果园旁 | 买长椅/路灯/盆栽/栅栏/喷泉 |
| 种子店 | 南侧 | 买胡萝卜/番茄/南瓜/草莓种子，支持 ×5 批量 |
| 码头 | 南岸 | 钓鱼最佳位置 |
| 房屋 | 玩家 + 5 位居民 | 可进入，每个房间有独立布局与互动 |

## 种植

翻土（铁铲）→ 播种（种子或岛建「农事」工具）→ 浇水（浇水壶，每天一次）→ 跨天后生长 → 成熟后「收获」。
作物有胡萝卜(3天)、番茄(4天)、南瓜(5天)、草莓(4天)，未浇水当天不长；收获给 1~2 个产物并返还 1 颗种子。

## 钓鱼

面朝水面用钓竿抛竿 → 等待 1.4~3.8 秒 → 浮漂下沉时再点「使用」收竿。
共 12 种鱼，分河/海与昼夜偏好，稀有度从常见到传说；钓到的鱼计入图鉴（图书馆可查看），可在杂货铺出售。

## 关系

与每位居民的好感分 5 档（陌生 / 点头之交 / 熟人 / 好朋友 / 挚友），交谈 +3，送出手上的贝壳/花苗/苹果再 +6；
居民之间也有独立的两两关系，会因性格契合度交好或闹别扭。运动场里可以查看全局关系。

## 时间与存档

- 时间、季节取自设备本地时间，05:00 为跨天分界；游戏内跨过 05:00 会自动结算施工。
- 存档：`user://little_island_diary_save_v2.json`，同目录保留 `.bak` 备份；写入流程为「临时文件 → 回读校验 → 备份旧档 → 转正」，任一步失败都会回滚。
- 存档版本 `8`：v5 存档可直接读取；**v4/44×44 的旧地图存档**会在读取时保留金币、背包、好感与设置，岛屿按新版本重建，旧档另存为 `little_island_diary_save_legacy44.json`。
